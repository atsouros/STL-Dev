That actually sounds like what we would prefer - multiple statistical realizations which are not locked to "Planck truth" at low ell. Ideally we would like 500 realizations since that is our standard number. But fine to start with one or a handful.

The ell range we care about is roughly 30<ell<500. Probably fine to drop the upper end to 300 if that were to make a difference to you. We would like nside=512 maps for input to our machinery. And I guess we will need maps at each bandpass where we would need to send those to you.

It would be best if the dust (and sync?) amplitude roughly matches the real data constraints set in the BK18 paper  - in particular please check the decorrelation parameter on the sky mask which is available on our website (http://bicepkeck.org/bk18_2021_release.html) - the paper shows the data constraint in fig18.
